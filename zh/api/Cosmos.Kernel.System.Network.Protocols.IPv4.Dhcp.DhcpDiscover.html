DhcpDiscover(MacAddress)

Initializes a new instance of the DhcpDiscover class as a broadcast discover. Writes DHCP option 53 (message type) with value 1, DHCPDISCOVER, then option 55, a parameter request list asking for options 1 (subnet mask), 3 (router), 15 (domain name) and 6 (domain name server), then the end mark.
