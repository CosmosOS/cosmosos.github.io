Obtains an IPv4 configuration for one network adapter from a DHCP server: the primary adapter by default, or the one handed to the constructor. The exchange leaves through that adapter alone and only that adapter's configuration is touched; every other adapter keeps its own.

Methods

SendDiscoverPacket()

Runs the DISCOVER, OFFER, REQUEST, ACK exchange on the adapter and applies the lease to it. The adapter's configuration is replaced when the server acknowledges and left as it was otherwise; no other adapter is touched.

public int SendDiscoverPacket()

Returns

int

The milliseconds waited, or -1 when no lease was obtained: no reply arrived in time, or the server declined with a NAK.

Exceptions

InvalidOperationException

The adapter names no registered device, or the server answered with an offer or an ACK that carries no client address.

SendReleasePacket()

Tells the server the adapter's address is free again and drops the adapter's IP configuration, leaving it unconfigured. The server is taken to be the adapter's default gateway. Other adapters are left alone.

public void SendReleasePacket()

Exceptions

InvalidOperationException
