Class DeviceRegion

A bulk device region mapped through MapRegion(int, RegionCaching): a framebuffer, a command queue, a descriptor area. Where a RegisterWindow checks and orders every access, a region is memory: Span fills it, As<T>() copies structs into it, and the driver orders what needs ordering with WriteBarrier() and ReadBarrier(). Slice(ulong, ulong) carves a sub-range that goes dead with its parent. The accessors neither allocate nor block.

Slice(ulong, ulong)

A region over length bytes of this one starting at offset, with the same caching, that shares this region's invalidation: once this region (or the one it was sliced from) is torn down, the slice throws too. Thread context. The slice is not a kit resource of its own: it is not in the binding's ledger and not counted by its held resources.
