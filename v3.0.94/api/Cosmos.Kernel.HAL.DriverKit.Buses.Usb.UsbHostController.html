Class UsbHostController

The contract a USB host controller driver implements for the kit: how a device on a port gets its address and how its state is freed again. The host driver binds the controller's own node (a PCI function for xHCI), creates a UsbBus over this object from its probe, and owns every register, ring, context and DMA page; the kit never publishes a node for the controller itself. A host implements the protected members; the kit calls them through the internal ones, so a class driver holding a reference can reach neither.

ReleaseDeviceCore(UsbDevice, bool)

Frees the host's state for a device the kit no longer tracks. Thread context. With hostPresent the host first waits out any transfer still running on the device and tells the controller the slot is free; without it (the controller's own hardware is gone) nothing is written and the state is only dropped. Called after every interface node of the device was torn down: the kit never releases a device whose nodes still have a live binding (an attach over a stale state refuses it rather than detaching it from the worker).
