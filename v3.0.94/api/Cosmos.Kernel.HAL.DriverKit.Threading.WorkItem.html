Class WorkItem

Namespace
Cosmos.Kernel.HAL.DriverKit.Threading
Assembly
Cosmos.Kernel.HAL.dll

A callback that runs in thread context on the kit worker, created through CreateWorkItem(Action). Scheduling it from a handler is how interrupt work reaches a context that may block: the item is queued at most once at a time and allocation-free, because it owns its queue entry. Teardown cancels it; a cancelled item never runs again.
