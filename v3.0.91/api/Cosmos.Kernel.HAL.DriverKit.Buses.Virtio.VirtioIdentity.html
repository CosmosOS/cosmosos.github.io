Class VirtioIdentity

Namespace
Cosmos.Kernel.HAL.DriverKit.Buses.Virtio
Assembly
Cosmos.Kernel.HAL.dll

The identity of a virtio device as its transport driver published it: which transport carries it, the transport's own address for it, and the device type. The path is virtio:pci:0000:00:03.0 or virtio:mmio:a003e00: the transport is visible in the path and invisible to the leaf driver, which matches on the type alone. Built by a transport driver in Cosmos.Kernel.Drivers, so the constructor is public. Any context.
