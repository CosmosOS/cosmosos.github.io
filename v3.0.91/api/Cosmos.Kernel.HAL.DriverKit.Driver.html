Class Driver

Cosmos.Kernel.HAL.DriverKit

Base class of every driver the kit can bind. A driver declares what it matches, is offered nodes that match, and in Probe(DeviceBinding) either takes a node, acquiring what it needs through the binding, or passes.

The manifest constructs one instance per driver class, and that instance is offered every node it matches, so fields on the driver are shared across bindings: state that belongs to one device lives on objects the driver creates in Probe(DeviceBinding) and hangs off DriverState. Probes, teardowns and work items run one at a time on the kit worker; only driver threads run concurrently, with each other and with the worker.

Execution contexts: Probe(DeviceBinding) and OnDetach(DeviceBinding, DetachReason) run in thread context on the kit worker and may block through the binding. Interrupt handlers requested through the binding run in interrupt context and reach only what the binding says they may.
