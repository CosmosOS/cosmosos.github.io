Class WaveAudioStream

Namespace
Cosmos.Kernel.System.Audio
Assembly
Cosmos.Kernel.System.dll

A RIFF/WAVE stream read straight off a volume, a block at a time. The chunk list is walked over the file handle rather than over a buffer, so nothing larger than one chunk header is held to find the frames, and a file of any size plays in a fixed amount of memory. The handle stays open for the life of the stream and belongs to whoever opened it.
