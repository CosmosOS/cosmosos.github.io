Where the kit placed the three rings of one split virtqueue in physical memory: built by TryCreateQueue(DeviceBinding, ushort, ushort, out Virtqueue?), consumed by a transport's ActivateQueue(ushort, in VirtqueueLayout), which programs the addresses (a modern transport) or the page frame number and the alignment (a legacy MMIO transport). Any context.
