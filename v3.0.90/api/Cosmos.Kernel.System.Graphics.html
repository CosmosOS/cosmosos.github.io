Bitmap

Represents a bitmap image.

Canvas

A drawing surface: a buffer of raw ARGB pixels, either off-screen or attached to a display the driver kit published. Every primitive draws into the buffer; a display-backed canvas copies it to the display's framebuffer in Display(), so it is double buffered and its pixels read back exactly as drawn. Subclassed by Canvas3D for a display that renders 3D.

DisplayDevice

One published display as the ring sees it: the name the driver gave it, which driver published it (or the firmware), where it sits in the device tree, and its mode read live from the driver. Created by Cosmos.Kernel.System.Graphics.KitDisplayConsumer when the kit publishes a display and kept in DisplayManager's list until it is withdrawn; a canvas holds one to draw on. Once withdrawn the mode reads as zero and no facet is found, and the contract object behind it is never read again: the identity members are copied at creation, so they stay readable.

DisplayManager

The displays the kit published, and which one is primary: the firmware framebuffer the bootloader handed over, published by the engine before it starts, and every display a kit driver publishes, which the manager's Cosmos.Kernel.System.Graphics.KitDisplayConsumer lists from the kit worker and drops when it is withdrawn. GetFullScreen() draws on the primary display. Reads answer honestly before Cosmos.Kernel.System.Graphics.DisplayManager.Initialize() ran and when graphics are compiled out: 0, null, false.

Image

Represents a raster image.

KernelConsole

Cell-based graphics console for kernel output. Uses a character grid (cells) similar to Aura OS for efficient terminal rendering. Can be instantiated on any canvas (hardware or virtual).

Png

Represents a PNG image. All PNG color types are supported (grayscale, truecolor and palette, with or without alpha), at every legal bit depth, with or without Adam7 interlacing. Decoding is done entirely in managed code by the vendored BigGustave decoder and SharpZipLib inflater (see the Credits page of the documentation).
