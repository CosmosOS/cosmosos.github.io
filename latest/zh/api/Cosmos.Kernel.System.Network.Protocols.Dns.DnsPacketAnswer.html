构造函数

DnsPacketAnswer(byte[])

Parses a DNS response from a received frame. The buffer is aliased without copying. The whole message is parsed during construction: header counts, the question and answer sections, and the names, compressed or inline. The parse stops at the first malformed section, and Truncated reports it: Queries then holds the questions read before it, and Answers the answers. Nothing is read past the UDP length, and nothing throws. When the reply code is not OK, section parsing is skipped and both lists stay null.

属性

Truncated

Whether the parse stopped before the sections the header announced were complete: a message shorter than its UDP length, a name or a record running past the message's end, or a label with a reserved length. The sections read before the stop are kept.
