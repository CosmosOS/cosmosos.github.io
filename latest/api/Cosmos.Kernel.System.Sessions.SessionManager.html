Remarks

The primary console, tty1, is Default. It is the session of every thread that was not started on another one, the kernel's main loop among them, and it cannot be closed.

Once a second session exists, the keyboard is routed: each key goes to the session on the display, and Alt with F1 to F12 shows session 1 to 12, Alt with the left or right arrow the previous or next one. From then on KeyboardManager's read members, like Console, read the calling thread's session.
