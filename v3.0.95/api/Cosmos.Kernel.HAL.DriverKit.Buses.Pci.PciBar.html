One base address register of a PCI function as the host sized it at describe time: what the slot decodes, where, and how much. The six slots are always reported; the upper half of a 64-bit register and a slot with no register behind it are unassigned with length 0; an implemented register nobody has assigned yet is unassigned with the length its mask decoded, which is what the kit's placement for a function arriving behind a hot-plug slot uses. The resource at the same index on the node is the mappable form.
