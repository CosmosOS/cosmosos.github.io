Class AudioPlayer

Namespace
Cosmos.Kernel.System.Audio
Assembly
Cosmos.Kernel.System.dll

Pushes an AudioStream into an AudioDevice until the stream runs out. The device owns the ring and drains it on the codec's clock; the player only keeps it fed, which is why it neither allocates per buffer nor runs from an interrupt.

Thread context: Play(AudioStream) blocks for the length of the audio, and claims the output for as long as it runs, so two players cannot interleave frames into one ring. TryStart(AudioDevice, AudioStream, IDisposable?, out AudioPlayback?) runs it on a thread of its own for a caller that must stay responsive; RequestStop() ends it early and is safe from any context.

RequestStop()

Asks the playback to end early. Play(AudioStream) stops feeding, drops what the ring still holds and returns. The request is final: this player plays nothing more, which is what lets it be made before Play(AudioStream) is even reached, as a stop asked for while the playback thread is still starting up is. Allocation-free and safe from any context, including an interrupt.
