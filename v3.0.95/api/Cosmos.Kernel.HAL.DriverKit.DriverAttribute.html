Marks a Driver class for the manifest the build generates. The kernel project's manifest registers every marked class it can see, in a fixed order (the kernel's own classes in declaration order, then referenced assemblies by name), subject to the kernel's policy: a CosmosDriverExclude item drops a driver, a CosmosDriverInclude item adds one whose Default is false, and Feature ties the registration to a feature switch.

[AttributeUsage(AttributeTargets.Class, Inherited = false)]
[Experimental("COSMOS0003")]
public sealed class DriverAttribute : Attribute

The feature switch the driver depends on. The manifest guards the registration with the matching KernelFeatures property, so the driver and everything only it references fold out of a kernel that turns the feature off. None by default.
