Namespace Cosmos.Kernel.System.Graphics.Rendering3D

Classes

Canvas3D

A canvas backed by a device that can render 3D primitives. On top of the 2D Canvas surface, a 3D canvas draws device-owned meshes (CreateMesh(ReadOnlySpan<Vector3>, ReadOnlySpan<uint>, ReadOnlySpan<ushort>), DrawMesh(Mesh, in Matrix4x4)) as seen through Camera. A frame is composed by calling ClearScene(Color, float), issuing draw calls, and presenting with Display().

Mesh

A set of 3D primitives uploaded to a 3D device. Created with one of the Canvas3D CreateMesh overloads and drawn with DrawMesh(Mesh, in Matrix4x4); dispose it to release the device memory it occupies.

Texture

An image uploaded to a 3D device, ready to be mapped onto meshes. Created with CreateTexture(Image); dispose it to release the device memory it occupies.

Structs

Camera3D

Describes the point of view used for 3D drawing on a Canvas3D. The aspect ratio always comes from the canvas mode, so a camera only carries where it stands, what it looks at, and its field of view.
