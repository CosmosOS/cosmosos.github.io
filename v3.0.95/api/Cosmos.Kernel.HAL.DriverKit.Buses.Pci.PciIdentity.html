Class PciIdentity

Namespace
Cosmos.Kernel.HAL.DriverKit.Buses.Pci
Assembly
Cosmos.Kernel.HAL.dll

The identity of a PCI function as its configuration header states it: where it is (segment, bus, device, function) and what it is (vendor, device, subsystem, class, revision, header layout). Read once by the host that described the function; never changes. Path is pci:ssss:bb:dd.f, all hexadecimal.
