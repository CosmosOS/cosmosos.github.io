Class VirtioTransport

Namespace
Cosmos.Kernel.HAL.DriverKit.Buses.Virtio
Assembly
Cosmos.Kernel.HAL.dll

What a transport driver implements over its registers so the kit's VirtioAccess can run the status handshake, the feature negotiation and the virtqueues once, for every transport. The kit calls these members; a leaf driver never sees the transport, only the access. A transport driver in Cosmos.Kernel.Drivers derives from this, so the constructor is protected and the members are public abstract. The execution context of each member is in its summary.
