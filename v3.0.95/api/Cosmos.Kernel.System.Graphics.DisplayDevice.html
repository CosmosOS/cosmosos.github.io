Class DisplayDevice

Namespace
Cosmos.Kernel.System.Graphics
Assembly
Cosmos.Kernel.System.dll

One published display as the ring sees it: the name the driver gave it, which driver published it (or the firmware), where it sits in the device tree, and its mode read live from the driver. Created by Cosmos.Kernel.System.Graphics.KitDisplayConsumer when the kit publishes a display and kept in DisplayManager's list until it is withdrawn; a canvas holds one to draw on. Once withdrawn the mode reads as zero and no facet is found, and the contract object behind it is never read again: the identity members are copied at creation, so they stay readable.
