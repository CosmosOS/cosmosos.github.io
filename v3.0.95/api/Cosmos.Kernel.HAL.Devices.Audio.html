Namespace Cosmos.Kernel.HAL.Devices.Audio

Classes

AudioSink

Where an audio driver reports that it drained a buffer or changed format, returned by PublishAudio(IAudioOutput). Kit-owned; see KeyboardSink. Allocation-free; any context, so the driver may report a completion straight from its interrupt handler.

Structs

AudioFormat

The layout of one audio frame: how many bits a channel holds, how many channels a frame interleaves, and whether the samples are signed. A format is not a rate: SampleRate carries that, because the same layout plays at every rate the codec accepts.

Interfaces

IAudioOutput

What an audio output driver implements and hands to PublishAudio(IAudioOutput). The kernel pushes frames in with Write(ReadOnlySpan<byte>) and the device drains them on its own clock, the mirror of Transmit(ReadOnlySpan<byte>): the driver owns the ring, the caller never blocks on it, and a short write is how the device says it is full. The driver reports the room it frees through BufferCompleted(). Called by the ring in thread context.

Enums

AudioBitDepth

Bits per sample in one channel. The value is the channel's size in bytes, so (int)depth is what a stride calculation needs.
