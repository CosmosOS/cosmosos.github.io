Class InterruptTrampoline

Namespace
Cosmos.Kernel.HAL.DriverKit.Interrupts
Assembly
Cosmos.Kernel.HAL.dll

The kit's dispatcher between an InterruptSource and a driver's InterruptHandler. The source calls Invoke(bool) with interrupts masked; the trampoline enters the interrupt-context guard, runs the handler, and turns an exception into a recorded fault instead of a crash: the fault is counted on the node, the source is masked so a handler that throws once cannot throw on every delivery, and a preallocated work item logs it in thread context. Nothing here allocates: the message kept is the exception's own.
