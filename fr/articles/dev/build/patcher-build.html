Vue d'ensemble

Cosmos.Patcher.Build intègre l'outil Cosmos.Patcher au pipeline MSBuild. Cosmos.Patcher réécrit l'IL des assemblies candidats en y appliquant des plugs à la manière de CosmosOS, afin que le framework .NET Core puisse s'exécuter sur des cibles NativeAOT. L'analyse statique est assurée par Cosmos.Patcher.Analyzer, qui signale les erreurs de plug pendant la compilation C#, avant que le moindre IL ne soit réécrit.

Structure d'un assembly .NET

Un assembly .NET (.dll ou .exe) est un exécutable portable qui contient des métadonnées et du code IL. Le patcher manipule ces structures à l'aide de Mono.Cecil.

Paramètres

Nom Description Valeur par défaut
EnablePatching Active ou désactive le patching. true
CosmosPatcherExe Chemin de l'exécutable Cosmos.Patcher. %USERPROFILE%\.dotnet\tools\cosmos.patcher.exe sous Windows, cosmos.patcher sous Unix
PatcherOutputPath Répertoire dans lequel les assemblies patchés sont écrits. $(IntermediateOutputPath)/cosmos/ref/
PlugReference Noms des assemblies de plugs à inclure. aucun

Tâches

Tâche Description Dépend de
SetupPatcher Rassemble les assemblies candidats, résout les références de plugs et prépare les répertoires de sortie. Build, ResolveIlcPath
RunPatcher Exécute Cosmos.Patcher pour chaque entrée de AssembliesToPatch. SetupPatcher
CleanPatcher Supprime les fichiers générés par le patcher. Clean
FindPluggedAssembliesTask Filtre les assemblies candidats pour ne garder que ceux qui contiennent des types cibles. SetupPatcher
PatcherTask Enveloppe MSBuild autour de Cosmos.Patcher pour les scénarios personnalisés. aucune

Déroulement détaillé

  1. SetupPatcher rassemble les assemblies de sortie et de référence, résout les références de plugs et les stocke dans $(IntermediateOutputPath)/cosmos.

  2. FindPluggedAssembliesTask utilise PlugScanner.FindPluggedAssemblies pour croiser les cibles des plugs avec les assemblies candidats, et produit AssembliesToPatch.

  3. RunPatcher parcourt AssembliesToPatch et, pour chaque assembly, la PatcherTask lance la CLI Cosmos.Patcher (Program → PatchCommand.Execute). Dans Execute :

    • L'assembly cible et les assemblies de plugs sont lus par PatcherAssemblyLoader avec un PatcherAssemblyResolver qui cherche dans les répertoires de la cible, des plugs et de la sortie, ainsi que dans ceux que RunPatcher transmet avec --search (cosmos/ref et le répertoire de chaque assembly candidat). L'écriture d'un assembly patché résout les types de ses constantes : un champ const ou un paramètre par défaut dont le type est une énumération d'un autre assembly Cosmos exige que cet assembly soit trouvé, et le résolveur par défaut de Mono.Cecil ne cherche que dans le répertoire courant et dans le runtime hôte.
    • PlugScanner.LoadPlugs découvre les types de plugs dans ces assemblies.
    • PlugPatcher.PatchAssembly regroupe les plugs par cible [Plug] et patche chaque type cible à l'aide de :
      • MethodResolver, qui fait correspondre les signatures des plugs (constructeurs et paramètres aThis compris) par nom et par types de paramètres.
      • PlugPatcher.Method, qui échange ou clone l'IL et supprime les métadonnées P/Invoke.
      • ILCloner, qui clone les instructions, remappe les paramètres et corrige les cibles de branchement.
      • TypeImporter, qui importe de façon sûre les références de types, de méthodes et de champs, en corrigeant les autoréférences qui produiraient des métadonnées IL invalides.
      • PlugPatcher.Property, qui relie les getters et les setters aux implémentations des plugs.
      • PlugPatcher.Field, qui copie les valeurs constantes et redirige les accès aux champs.
    • L'assembly patché est écrit dans PatcherOutputPath.

  4. CleanPatcher supprime la sortie patchée lorsque le projet est nettoyé.

  5. Cosmos.Patcher.Analyzer valide les règles des plugs pendant la compilation, afin de détecter les erreurs avant le patching.

Sorties

  • Assembly applicatif patché : $(IntermediateOutputPath)/cosmos/$(AssemblyName)_patched.dll, la sortie principale du projet après application des plugs.
  • Assemblies de référence pour ILC : $(IntermediateOutputPath)/cosmos/ref/*.dll, patchés là où des plugs s'appliquent ; sinon copiés sans modification pour la résolution.
  • Les répertoires intermédiaires sont créés à la demande sous $(IntermediateOutputPath)/cosmos/.

Remarques :

  • RunPatcher ne s'exécute que lorsque EnablePatching vaut true, et après que SetupPatcher a calculé @(AssembliesToPatch) et les destinations.
