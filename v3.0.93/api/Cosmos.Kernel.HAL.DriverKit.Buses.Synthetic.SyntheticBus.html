Class SyntheticBus

Namespace
Cosmos.Kernel.HAL.DriverKit.Buses.Synthetic
Assembly
Cosmos.Kernel.HAL.dll

A bus with no hardware behind it, for tests: publishes nodes on demand, retracts them, and raises their interrupts. A node may carry a register window backed by one RAM page, so MapRegisters(int), MapRegion(int, RegionCaching) and the test can see each other's writes without remapping normal memory as device memory.
