Interface IRemovableMedia

命名空间
Cosmos.Kernel.HAL.Devices.Storage
程序集
Cosmos.Kernel.HAL.dll

A block device whose medium is read-only, removable, or both: a CD-ROM drive, a write-protected card. Optional facet on an IBlockDevice, found by a type test on the published object. The storage manager reads it to carry a read-only medium as one whole-medium partition without scanning it for a table, and to order it after every writable disk; a kernel reads it to tell a CD from a disk. Any context.
