KeyMapping

Represents a physical to virtual key mapping.

KeyboardLayout

Represents the base class for keyboard layouts.

KeyboardManager

Manages keyboard input from every keyboard a driver kit driver publishes (the PS/2 keyboard on x64, virtio and USB keyboards), which the manager's Cosmos.Kernel.System.Input.KitKeyboardConsumer registers from the kit worker when it is published and unregisters when it is withdrawn.

MouseManager

Manages mouse input from every pointer a driver kit driver publishes (the PS/2 mouse on x64, virtio mice), which the manager's Cosmos.Kernel.System.Input.KitPointerConsumer registers from the kit worker when it is published and unregisters when it is withdrawn.
