Where a background AudioPlayback has got to.

public enum AudioPlaybackState : byte

Champs

Completed = 1

The stream was played to its end and the output drained it.

Failed = 3

The output refused the stream's format, was withdrawn or busy, or reading the stream threw. Nothing, or only part of the stream, played.

Playing = 0

The thread is still feeding the output.

Stopped = 2

Stop() ended it early, so what the ring still held was dropped rather than played.
